# 1-3(mission3) 직접 써보고 피드백 주고받기

코디세이 AI 네이티브 입학연수과정 미션3 제출물.

- **미션:** 동료의 페이지를 직접 써 보고 피드백을 보내고, 받은 의견을 하나씩 확인함.
- **한 것:** 완성 기준별로 직접 써 본 메모 작성. 받은 의견 9개를 직접 해 보고 반영 5·되묻기 3·보류 1로 정리함.
- **결과:** 민수 님께 보낼 피드백 작성. 아무도 말하지 않은 불편(되돌리기 안내가 안 보임, 추가한 영화 삭제 불가)도 찾아 적음.
- **완성본:** `피드백.md`

## 파일 목록

- `미션3_기록.md`
- `민수_영화티어리스트.html`

## 파일 이름 규칙

- 폴더 안은 `html/`(페이지), `md/`(기획서·기록), `대화 캡처/`(AI와 나눈 주요 대화)로 나눔.
- 대화 캡처는 `AI이름_대화캡처번호.png`로 저장. 예: `claude_대화캡처1.png`, `chatgpt_대화캡처1.png`.
